Gestion des Allergies

ℹ️ Application prête à l'emploi avec XAMPP! Les tables sont créées automatiquement.

📋 Installation Rapide

1

XAMPP Control Panel

Ouvrez XAMPP et démarrez Apache et MySQL

2

Localisation du dossier

Le dossier doit être dans: C:\xampp\htdocs\gestion-allergies

3

Accéder à l'application

La base de données se crée automatiquement au premier accès!

✓ Configuration: localhost | Base: gestion_allergies | User: root | Pas de mot de passe
👁️ Voir le FrontOffice 🔐 Aller à l'Admin

Si vous voyez des erreurs de connexion BD:

✓ Vérifiez que MySQL est démarré
✓ Que vous êtes sur localhost
✓ Rechargez la page
