📊 Tables Créées Automatiquement

1. Table: allergie

CREATE TABLE allergie ( id_allergie INT AUTO_INCREMENT PRIMARY KEY, nom VARCHAR(100) NOT NULL UNIQUE, description TEXT, niveau_danger VARCHAR(50) NOT NULL, symptomes TEXT, type VARCHAR(50) NOT NULL, date_creation TIMESTAMP DEFAULT CURRENT_TIMESTAMP, date_modification TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
Colonne Type Contraintes Description
id_allergie INT PK, AUTO_INCREMENT Identifiant unique
nom VARCHAR(100) NOT NULL, UNIQUE Nom de l'allergie
description TEXT Nullable Description détaillée
niveau_danger VARCHAR(50) NOT NULL faible, moyen, élevé, critique
symptomes TEXT Nullable Symptômes observés
type VARCHAR(50) NOT NULL alimentaire, médicament, environnemental, contact, autre
date_creation TIMESTAMP AUTO Date de création
date_modification TIMESTAMP AUTO Date de modification

2. Table: traitement

CREATE TABLE traitement ( id_traitement INT AUTO_INCREMENT PRIMARY KEY, nom VARCHAR(100) NOT NULL, type_traitement VARCHAR(100), dosage VARCHAR(100), duree VARCHAR(100), effets_secondaires TEXT, date_creation TIMESTAMP DEFAULT CURRENT_TIMESTAMP, date_modification TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

3. Table: allergie_traitement (Jointure)

CREATE TABLE allergie_traitement ( id INT AUTO_INCREMENT PRIMARY KEY, id_allergie INT NOT NULL, id_traitement INT NOT NULL, date_ajout TIMESTAMP DEFAULT CURRENT_TIMESTAMP, FOREIGN KEY (id_allergie) REFERENCES allergie(id_allergie) ON DELETE CASCADE, FOREIGN KEY (id_traitement) REFERENCES traitement(id_traitement) ON DELETE CASCADE, UNIQUE KEY unique_allergie_traitement (id_allergie, id_traitement) ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

🔐 Sécurité

  • ✅ InnoDB: Support transactions et clés étrangères
  • ✅ Constraints: UNIQUE, NOT NULL, FK

📥 Charger les Données de Test

Optionnel: Si vous voulez des données de test pré-remplies.

Via PHPMyAdmin

  1. Aller à: http://localhost/phpmyadmin
  2. Sélectionner la base gestion_allergies
  3. Onglet "Importer"
  4. Charger le fichier: data/test_data.sql
  5. Cliquer "Exécuter"

Via Ligne de Commande

mysql -u root gestion_allergies < data/test_data.sql

✅ Vérification

Pour vérifier que les tables sont créées, exécuter dans PHPMyAdmin:
SELECT TABLE_NAME FROM information_schema.TABLES WHERE TABLE_SCHEMA = 'gestion_allergies';

🚀 Démarrage Rapide

  1. Démarrer Apache + MySQL (XAMPP Control Panel)
  2. Placer le dossier dans C:\xampp\htdocs\gestion-allergies\
  3. Accéder à: http://localhost/gestion-allergies/admin.php
  4. ✨ La base se crée automatiquement!

📞 Troubleshooting

❌ "SQLSTATE[HY000] [2002]"

↳ MySQL n'est pas démarré. Lancer XAMPP Control Panel.

❌ "Access denied for user 'root'@'localhost'"

↳ Vérifier credentials: user=root, pwd=vide (pas de mot de passe)

❌ "Table already exists"

↳ Normal au premier accès (création auto). Ou éxécuter en PHPMyAdmin:
DROP DATABASE gestion_allergies;

❌ "Unknown database 'gestion_allergies'"

↳ Recharger la page. La base se crée automatiquement.
